Cytogenetics · ISCN readout

ISCN Validator & Interpreter

A prototype for parsing and interpreting karyotype and FISH (ish / nuc ish) nomenclature strings.

Coverage

What this prototype currently understands

  • Numerical+N / -N (gain/loss of a chromosome), +mar / -mar
  • Structuralt() translocation, del() deletion, dup() duplication, inv() inversion, i() isochromosome, r() ring, add() addition, ins() insertion, der() (decomposed), rob(), mar, dmin, hsr()
  • Mosaicismmultiple clones separated by "/", with [N] cell counts
  • Batch inputone ISCN string per line parses each independently, results labeled by input order — paste directly or upload a plain-text .txt file
  • FISHnuc ish(...) and ish(...) probe results — probe+, probe-, probeXN, fusion ("con"), amplification ("amp"), with reference notes for well-known probes
  • Validationmodal number format, sex chromosome constitution, band format, a soft cross-check between the stated modal number and the numerical abnormalities listed, and approximate band-plausibility / breakpoint-order checks

Anything not listed above (e.g. uncertainty markers like "?", some complex multi-step rearrangements) is flagged as unrecognized rather than guessed at. The edition selector is a scaffold — only a couple of illustrative edition-specific notes are wired up so far; see the README.
